# Life Hack or Urban Myth? Quiz App

An Android quiz application that helps users distinguish between genuine life hacks and urban myths.

##  Features

- **Welcome Screen**: Introduction to the app with a start button
- **Interactive Quiz**: 10 questions testing knowledge of life hacks vs myths
- **Real-time Scoring**: Track your score as you progress
- **Instant Feedback**: Get explanations after each answer
- **Review Mode**: Review all questions and correct answers
- **Personalized Results**: Score-based feedback messages

##  Technologies Used

- **Language**: Kotlin
- **IDE**: Android Studio
- **Minimum SDK**: API 24 (Android 7.0)
- **UI Components**: 
  - ConstraintLayout
  - CardView
  - RecyclerView
  - Material Design Components

## How to Play

1. Tap **Start Quiz** on the welcome screen
2. Read each statement carefully
3. Choose **Life Hack (True)** or **Urban Myth (False)**
4. Get instant feedback with explanations
5. Complete all 10 questions
6. View your final score
7. Review all answers to learn more

## Sample Questions

- "Putting your phone in rice will fix water damage" - **Urban Myth**
- "Use a wooden spoon across a boiling pot to prevent overflow" - **Life Hack**
- "Freezing jeans instead of washing them keeps them fresh" - **Urban Myth**
